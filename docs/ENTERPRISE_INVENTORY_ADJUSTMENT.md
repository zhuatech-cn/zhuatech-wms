## 业务闭环

盘点任务关闭 → 独立复盘 → 批次/序列追溯 → 权属与质量确认 → 成本影响复核 → 财务与业务批准 → 调整过账 → 根因整改。

## 过账门禁

- 原盘点任务必须关闭，并由不同人员完成复盘。
- 批次、序列号、容器、质量状态和库存权属必须清晰，不得形成负库存。
- 差异价值必须在审批权限内，库存成本影响必须经复核。
- 财务与仓库/货主负责人必须批准，盘点、调整与复核必须职责分离。
- 盘点、复盘、审批和过账材料必须形成完整审计证据。

## 接口与决策

`POST /api/enterprise/wms/inventory-adjustment`

返回 `POST`、`REVIEW` 或 `BLOCKED`。ERP、财务、自动补货和仓库设备仅预留适配方式，项目不保存真实外部凭据。
