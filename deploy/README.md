## 本地容器启动

```bash
cp .env.example .env
docker compose up --build -d
docker compose ps
```

前端入口为 `http://localhost:8088`。Nginx 将 `/api` 转发到 Java 后端，后端连接 MySQL 并由 Flyway 管理表结构。

## 上线前必须完成

- 修改 MySQL 用户、root 密码、JWT 密钥和所有演示账号。
- 删除初始化演示数据并根据企业数据规范重新建档。
- 通过受信任反向代理启用 HTTPS、HSTS 和安全响应头。
- 仅允许后端网络访问 MySQL，禁止数据库直接暴露公网。
- 增加备份、恢复演练、日志采集、监控、告警和容量规划。
- 补充接口限流、登录保护、操作审计、数据权限与敏感字段脱敏。
- 对镜像、依赖和许可证进行持续供应链安全检查。
